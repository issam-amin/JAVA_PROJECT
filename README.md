# Customer Data Analysis and Churn Prediction Dashboard

This project is a Java-based desktop application for analyzing customer data and predicting customer churn. It provides a user-friendly dashboard built with JavaFX to visualize key metrics and insights.

## Features

*   **User Authentication:** Secure login and session management.
*   **Interactive Dashboard:** An overview of key statistics and visualizations.
*   **Client Statistics:** View detailed statistics about clients.
*   **Churn Prediction:** Utilizes a machine learning model to predict customer churn.
*   **Data Visualization:** Includes various charts (pie charts, bar charts) to represent data.
*   **Complaint Tracking:** A section to view and manage client complaints.

## Prerequisites

Before you begin, ensure you have met the following requirements:
*   You have installed a recent version of Java (e.g., JDK 17 or later).
*   You have installed Apache Maven.
